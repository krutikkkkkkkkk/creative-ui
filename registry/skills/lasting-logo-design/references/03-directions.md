# 03 — Directions & Logo Types

Spread 4–6 directions across **at least three logo types** so the client sees real alternatives, not variations of one idea.

| Type | Best when | Watch out for | Lasting test |
|---|---|---|---|
| **Wordmark** | Name is short, distinctive and pronounceable | Off-the-shelf fonts with nothing ownable | One custom detail you'd recognise from a single letter |
| **Lettermark / monogram** | Long name; needs a compact icon | Monogram look-alikes; illegible ligatures | Readable as letters and as a shape |
| **Pictorial symbol** | A clear, ownable object exists in the brand nouns | Clichés, literalness, too much detail | Drawable from memory after one look |
| **Abstract mark** | Broad offer, many products, global audience | Meaningless shapes; similarity to others | Has a story; holds up without the name later |
| **Combination** | Most new brands | Parts that don't work alone | Symbol and wordmark each work separately |
| **Emblem / badge** | Heritage, craft, F&B, sports, institutions | Breaks small; text inside the badge | Comes with a simplified icon cut |
| **Mascot / character** | Consumer, community, playful brands | Ages fastest; hard to scale | A simplified head or silhouette version exists |

## Direction card template
```
### Direction 02 — "Thread S"
Type: Lettermark (combination with wordmark)
Concept: The S is drawn as a single curling saffron thread with a tapered end.
Story: "Every jar starts with one hand-plucked thread."
Why it fits: Ties the initial to the brand's provable differentiator (single-origin, hand-plucked).
Techniques: continuous line, letter as object, tapered stroke.
Risks: Monoline S marks are common, so the taper and thread tip must be distinctive. Thin strokes at 16px need a heavier small-size cut.
```

## Choosing which to recommend
Score each direction quickly before writing prompts:
- **Truth link** (does it come from a ★ noun?)
- **Distinctiveness** in the category
- **Simplicity** (fewer than ~5 distinct shapes)
- **Range** (works as icon, pattern and motion)

Mark one as **Recommended** and say why in one line.
