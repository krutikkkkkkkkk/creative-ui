# 07 — Page Blueprints

Four full landing-page blueprints. Each row lists the section, its layout, its metaphor image and example copy. Swap the copy, keep the rhythm.

Rhythm rule: alternate **dense** (cards, stats) and **calm** (statement, scroll story) sections. Never put two image-heavy sections back to back without a breathing section between them, unless they are stacked feature cards.

## Section count and length
- Landing page: 8–11 sections
- Desktop page height: 8–12 viewports (scroll stories add length; that's intended)
- Template product (Framer marketplace): add Pricing, FAQ, Blog index, About, 404 and Contact pages that reuse the same components
